# Branch-Out

**Find proof. Start small. Build trust through real work.**

Branch-Out helps people find credible collaborators and test whether they work
well together before making a large commitment. Instead of relying only on
profile claims, teams can review relevant work, agree on a small two-week
milestone, and build trust through observable collaboration.

## How trust works

Branch-Out presents three clear signals:

1. **Skill Screened** — practical judgment has been assessed in a focused
   challenge.
2. **Work Demonstrated** — previous work is visible and the person’s
   contribution is clear.
3. **Collaboration Proven** — a teammate has confirmed behavior observed while
   working together.

No single signal is treated as absolute proof. Each one describes a different
kind of evidence that people can consider when choosing a collaborator.

## What people can do

- Browse, search, and filter project openings.
- Review outcomes, commitments, compensation, access expectations, and proposed
  trial milestones.
- Save promising openings and compare them side by side.
- Create a collaboration profile supported by public work evidence.
- Apply to a specific project with a relevant sample and proposed first step.
- Post a project with clear scope, expectations, and compensation.
- Plan a bounded two-week trial before making a larger commitment.
- Record trial outcomes and build explainable trust from completed work.
- Report safety concerns and use the available review and appeal processes.

## The Branch-Out approach

A healthy collaboration should begin with clarity:

- Show relevant evidence instead of making broad claims.
- Define one small, reviewable first milestone.
- Agree on time, communication, access, confidentiality, and stopping
  conditions before work begins.
- Record outcomes using observable facts.
- Let both people retain control over their commitments and intellectual
  property.
